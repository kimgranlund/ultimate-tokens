# Four house rules get a gate each, and the em dash is swept off main before its gate lands at zero

Four rules in `.claude/CLAUDE.md` have no enforcer: the count of `html:` attributes the SVG-chart exception allows (#727), the `fill: none` rule for line-chart paths (#728), the no-em-dash rule (#730), and the claim that `test/repo/branding.mjs` scans every record under `.sdlc/` (#724, it skips `.txt` and `.log`). Each gets a check in `npm test`, each check has a control that fails, and the two that red today (#728 on two `styles.css` rules, #730 on the whole tree) get the fix that turns them green.

The owner ruled on #730 (question 1 of the triage): sweep main first, then gate at zero, no grandfather list. Four things the measurement found that the triage did not say. They change the work, so they come first.

1. The sweep is not 61 lines in `tonal.js` plus a handful of records. At a4675242 the tracked tree carries 16,744 em dashes outside Markdown inline code spans, on 12,338 lines in 343 of the 555 tracked text files. By directory: `figma/plugin` 4,374 (2,563 of them in the generated `ui.html`), `src/ui` 3,108, `docs/reference` 2,661, `.claude/skills` 1,199, `src/engine` 894, `test/engine` 519, `docs/marketing` 366, `test/ui` 343, `docs/tickets` 308, `plugin/ultimate-tokens` 297, `figma/binder` 296, `test/figma` 262, `docs/site` 233, `CHANGELOG.md` 148, and 30 in `.claude/CLAUDE.md` itself (27 lines). A hand sweep at that size is an L unit with a wide review; a mechanical one is an M unit whose diff can be checked by invariant and by a sampled read per rule. So the gate ships with a `--fix` mode, and the sweep is one run of it (measured below: the whole suite stays green after it).
2. The dash is a label separator far more often than a parenthetical. 565 Markdown headings (`## 1.63 — 2026-09-18 — title`, `### I·01 — 59° N`, `## Procedure — add a serializer`) and 441 bullets whose first token is a code span or bold label (a bullet, the span `npm test`, the dash, `the gate.`) use it between a label and its description; 348 lines end in it because the sentence continues on the next line; 31 lines start with it because the sentence continued from the line before. A single comma rule corrupts all of those (revision 1 did, and its numeric-range rule matched 128 separators and no range). Revision 2 has one rule per construct, each with the meaning it preserves stated, its count, and four real lines of its diff in this plan.
3. Twenty string literals in the product are the glyph alone: `"—"` as the empty-value placeholder in the section inspectors (`h("div", { class: "an-empty" }, "—")`), in a Figma Make table cell (`ds-export.js:1433`), in the MCP kit summary (`brand-kit-core.mjs:63`), and as the `GENERIC_FONTS` sentinel. Those are rendered output, not prose; rewriting them to `", "` would print `Systems in this kit: , .` (revision 1 did, and no test pins it). The owner ruled (Q3, 2026-09-22): replace them, the new text is `n/a`, as its own small unit with a test per surface (U6), plus the one doc line quoting the placeholder. So the gate exempts nothing but Markdown spans and `PINNED` copies; `--fix` never rewrites a lone token (plain, or backslash-escaped as the generated mirrors inline it, `\"—\"`, 6 at 36f463de) but sends the line to R0, so a late branch that reintroduces one is refused, not comma-ised. Three more Make export rows carry the dash as a table cell inside a template literal (`ds-export.js:1373`, `1461`, `1462`); U6 gives them `n/a` too.
4. The backtick exemption belongs to Markdown only, and two lines of code name the glyph on purpose. In a `.js` or `.mjs` file a backtick opens a template literal, which is a string the program prints; exempting those left 66 dashes in 11 generated files and went red in `test/engine/exports.mjs`. `.claude/skills/ultimate-tokens-brand-voice/scripts/voice-check.mjs:89` counts em-dash pivots in marketing copy with a regex carrying the literal glyph; a blind sweep turns it into `/, (?:not|never|no)\b/`, which matches every ordinary ", not" (the review reproduced both halves). `.sdlc/checks/doc-drift-rows-check.sh:19` and `.sdlc/scripts/roadmap-gen.mjs:28` already write it as a code point. The rule: code that must name the glyph writes the `u2014` escape (a backslash, the letter u, the four digits), never the character; the gate's own file follows it (P2 checks that the gate is not exempt from itself).

Scope wall. U1: `test/repo/svg-rules.mjs` (new), `test/run.mjs` (one entry), `src/ui/styles.css` (two lines). U2: `test/repo/branding.mjs`. U3: `test/repo/em-dash.mjs` (new). U4: every tracked file that carries the glyph, and only the lines that carry it or sit right before a line-start dash (rule R7 below), plus `test/run.mjs` (one entry), one hand edit in `voice-check.mjs`, the residual lines R0 names, and one line added to `.claude/CLAUDE.md` `## Always` (adapter X9: the owner's approval of this plan is the approval of that edit and of the 27 swept lines there). U5: `.sdlc/baseline.md`, `.sdlc/adapter.md` §1 (the test row's time range only). Every unit: its own handoff, verdict and questions under `.sdlc/`. `package.json` and `.github/workflows/ci.yml` are untouched: no new script, no new CI job, because every gate here runs in well under a second and belongs in `npm test` (#713 moves slow sweeps out; these are not slow).

Prose rules for every line this plan adds. No em dash outside an inline backtick span that quotes program output. No bold inline labels. The retired maker brand is paraphrased, never quoted. `grep -P` is absent on this host: PCRE runs through `perl -CSD`, and a flagless `perl -ne '/\x{2014}/'` on a byte stream never matches (#730 names this trap; measured below). Nine generated files carry `-diff` in `.gitattributes`, so every `git diff` that must see their lines says `--text`.

## The design, stated once

Four gates, three files. `test/repo/svg-rules.mjs` (U1) holds #727 and #728, because both are the entry file's SVG-chart rules and both read the same three section files. `test/repo/branding.mjs` (U2) keeps its shape and inverts its filter. `test/repo/em-dash.mjs` (U3, registered by U4) is the em-dash gate and its fix.

`svg-rules.mjs`. (a) Reads `.claude/CLAUDE.md`, takes the number from the line matching `SVG-chart exception: (\d+) live attributes`, counts `/\bhtml:\s*\w/g` over `src/ui/sections/{color,geometry,typography}.js`, fails on any difference, naming both numbers. (b) Collects every `<path class="<first-class>` in the same three files, in order of first appearance; for each class not in the AREA set (`lc-ceiling`, with the reason: a filled band, `stroke: none`, the rule at `styles.css` must declare a `fill` that is not `none`), requires `src/ui/styles.css` to hold a rule whose selector line starts `.an-svg .<class>` and whose block declares `fill: none`; fails naming the class and which half is missing (no qualified rule, or the rule without `fill: none`). An unknown class with no rule at all fails the same way, which is how a new line chart is caught. Its PASS line prints the two counts: `svg-rules: 12 html: attributes (stated 12), 6 line classes qualified with fill: none, 1 area class`.

`branding.mjs`. `TEXT` (an allow-list of 11 extensions) becomes `BINARY`, a deny-list: `woff2 woff ttf otf png jpg jpeg gif ico webp zip pdf`. Everything else the walk reaches is opened. Nothing else in the file moves: the walk, `SKIP_DIRS`, `SKIP_FILES`, `RECORDS`, the three patterns and the allow-list stay as they are. The scanned count rises by the 7 files named above.

`em-dash.mjs`. Reads `git ls-files -z` from the repo root (tracked files are what a commit ships; the gitignored `.sdlc/runtime/` and any scratch file never count), skips the same `BINARY` set, reads each file as UTF-8, and counts U+2014 per line after masking one thing: in a `.md` file, the inline spans (a backtick, any run of non-backtick characters, a backtick; the strip adapter §3 rules). Nothing else is masked: a template literal, a comment, a fenced block, a JSON string and a lone-glyph token all count (the owner's Q3 ruling replaces every placeholder with `n/a` in U6, so a lone token is a reintroduction). A second exemption exists for one case adapter §3 already rules: a byte-pinned verbatim copy in `.sdlc/verdicts/` that cannot be rewritten without breaking the hash its header states. The gate carries a `PINNED` set of paths, each entry with the header's hash beside it and the seat that pinned it, and skips only those files; the set is empty today (the one pinned body carries no dash), and adding to it is a pre-land reviewer's finding, never a builder's convenience. Any remaining count is a FAIL that names `path:line` for the first 40 hits and the totals: `FAIL: N em dashes outside inline code spans in M files`. Zero prints `em-dash: clean (K files scanned)`. The glyph is written in the source as the `u2014` escape only, so the gate's own file passes the gate. Before the tree scan it runs its self-test: a temp file carrying the glyph is written and read back through the same reader (so a byte-mode read fails the self-test, not just a spelling grep), then every row of the rule table above as an in-memory fixture (R0 (e) with the lone token in both its plain and its backslash-escaped form: refused, never comma-ised), the two exemptions, and idempotence; a broken rule fails before it can go vacuously green on the tree, and the self-test runs inside `npm test` every time, like `citations.mjs` runs the audit's self-test.

`--fix`. The same walk minus the generated files (the `GENERATED` set named under the rule table; `npm test` rewrites them from the swept sources), the same masking, then the R0 refusals first and the rules R1 to R8 of the table above, in that order, on the whole line with the masks in place; R1 and R2 fire in `.md` files only, R7 alone may edit the line before, and R0 leaves the line alone and prints it under the construct it matched. The file is written only if it changed, and the line count is asserted equal before and after. At the end it prints one count per rule, the R0 residual list, and (with `--sample`) four `path:line` before-and-after pairs per rule, which is what the reviewer reads. The rules are deterministic and idempotent (measured), so a late-landing branch runs the same command on its own tree and gets the same bytes main got, and a rebase conflict on a swept file is settled by taking the branch's side and running `--fix` again. `--fix` never touches a Markdown inline span, a `PINNED` file, the `u2014` escape, or a line R0 refuses (a lone-glyph token among them).

How a late-landing branch is caught. Once U4 is on `main`, `npm test` reds on any tree that carries the glyph, so `build-test` reds on the branch's PR the next time CI runs on it, and locally the moment its builder runs the gate. CI runs on `pull_request` pushes only, so a PR whose last green run predates U4's squash keeps that green: the landing step therefore checks that the newest run tested a merge ref containing U4's squash (`gh run view <id> --json headSha` and the run's `pull_request` merge commit both postdate it), and reruns CI with an empty commit or `gh run rerun` if not; and every plan's pre-land verifier already runs `npm test` on the branch with `origin/main` merged in (records-followup U9 did exactly this), which runs the gate. The repair is `node test/repo/em-dash.mjs --fix` on that tree, then `npm test` to regenerate the mirrors, then a commit. No allow-list, no baseline count, no merge-base arithmetic: the tree is clean or it is not. #681's 601 added dashes are swept by U4 itself because U4 starts only after #681 has landed (G0). `plan/gate-split` (#713) carries the same 601 plus one of its own; whether U4 waits for it is the Orchestrator's call from #713's state (the repair path covers either order).
