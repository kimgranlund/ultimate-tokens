# ADR-004 · Semantic scrim roles use base 750 only · 2026-07-12 · SUPERSEDED (2026-06-17 by the 500-ramp revision, recorded as ADR-023 on 2026-09-16; historical decision kept for provenance)
| Field | Value |
|---|---|
| Decision | Revert to 7 unqualified scrim roles (`scrimWeakest…scrimStrongest`) on base 750. Bases 250 and 500 remain raw primitives only. |
| Forces | Raw scrims existed on three bases (250/500/750 × 7 alphas), a revision had surfaced all three as semantic role families (21 roles), user clarified that 250/500/750 scrims belong as raw primitives, base 250 is a light tint overlay and 500 a saturated mid (different overlays, not weaker dark scrims) |
| Rejected | Three semantic scrim role families `scrim250*/scrim500*/scrim750*` (21 roles) |
| Consequences | 37 roles/palette (not 51). Tracked as OD-002 in case a use case for 250/500 semantic scrims appears. Superseding note: scrims are now a single 500-based ramp, a scrim is `500-{step}` = the 500 color at alpha% = step/10, all 12 scrim-using roles (the 7 `scrim*` + outline + container/Low/High) resolve onto it, mode-flat (light === dark); bases 250/750 are no longer used. |
