## Notes
- **The deliberate move:** a raw state with no `hueSpace` sent straight to an exporter (the MCP server or a hand-built caller) now renders `"oklch"` instead of `"cam16"`. `test/engine/controls.mjs` (a-export, b-bytes) covers it with cam16 controls. Hydrated documents and presets always carry `hueSpace`, and the neutrality run moved 0 of 344 subjects.
- **Base SHA:** `$SDLC_BASE_SHA` and `$SDLC_TMP_WORKTREES` were empty in this environment, so every criterion ran with the base SHA set inline. No gate went red, so no throwaway worktree was created.
- **How `report-compute-neutral.mjs` works:**
  - It archives `src` at the base rev into a temp dir that is removed on exit, and loads the subjects from the base tree.
  - It hydrates each subject once with the base `hydrate`.
  - It renders each subject on both trees through `projectView`, `figmaBundle`, `brandKit` (all three systems) and the three design-system bundles, called as drawer.js calls them, with a fixed date of `2000-01-01`.
  - It compares every leaf, and compares strings line by line.
- **"Same object" in item 7:** rendering runs in worker pools, one per tree, so a full run takes about 80 s instead of roughly 9 to 10 minutes on one thread. Each tree therefore gets a structured clone of the one base-hydrated document, not the same reference. The input is identical and nothing is hydrated twice.
- **`--perturb` shows 2 cells, not 1:** it flips one hex digit in `projectView.palettes[0].ramp[0]`. That stop object is shared with `fullRamp[0]`, so the change is counted twice.
- **Citation wording:** in `adding-export-formats/references/foundations.md` the new paths are written as ``src/engine/layers.mjs`'s `compute``` rather than the gated ``compute` (`src/engine/layers.mjs`)`` shape. `test/repo/citations.mjs` checks symbol homes against `git ls-files`, and the two new engine files stay untracked until the orchestrator commits. The gated shape can be restored once they are tracked.
