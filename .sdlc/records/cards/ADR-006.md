# ADR-006 · 3-digit zero padding everywhere · 2026-07-12 · DECIDED
| Field | Value |
|---|---|
| Decision | All stop references zero-pad to 3 digits (`pad3`/`refKey`) in CSS var names, CSS refs, JSON keys, DTCG names, and UI3 keys. Scrims keep `"{base}-{step}"` with padded base. CSS var prefix convention: RAW primitives and SEMANTIC roles both use the `--c-` prefix, raw as `--c-{family}-{stop|500-step}` and semantic as `--c-{family}-{role}`; a raw suffix always ends in DIGITS and a semantic suffix in a WORD. |
| Forces | Stops range 50–950, mixing `"50"` and `"050"` causes sort and lookup bugs, stable lexical sort, exact name matching against the user's `Color Primitives` collection (which is padded), no ambiguity, self-documenting raw/semantic split |
| Rejected | Raw vars under a `--c_` underscore prefix (the original 2026-06-17 convention, dropped for an all-hyphen namespace because the digit-vs-word suffix already disambiguates) |
| Consequences | Semantic vars reference raw vars via `var(--c-…)`; raw and semantic names never collide despite the shared prefix. |
| Supersedes / amended by | supersedes none stated; amended by CSS var prefix convention 2026-06-17, revised 2026-06-24 |
