# ADR-023 · Scrims are one 500-based alpha ramp, mode-flat (records the ADR-004 supersession) · 2026-09-16 · DECIDED
| Field | Value |
|---|---|
| Decision | A scrim is `500-{step}`: the palette's 500 color at alpha% = step/10, 3-digit padded (ADR-006), identical in light and dark. All twelve scrim-using roles (the seven `scrim*` strengths plus outline and the container Low/High family) resolve onto that ramp; bases 250 and 750 stay raw primitives. |
| Forces | ADR-004 put the seven scrim roles on base 750; a note inside it (2026-06-17) records that this was superseded, but the live model had no record of its own until this ADR. One saturated mid base reads as the same overlay in both modes; a per-mode base made scrims flip tone with the theme. |
| Rejected | none named |
| Consequences | `src/engine/semantic.js` emits every scrim ref as `500-NNN`; any change moves `role-table.json`, the binder table, and the count gates in lockstep (ADR-018). |
| Supersedes / amended by | Supersedes ADR-004 |
