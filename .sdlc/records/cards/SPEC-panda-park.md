# SPEC-panda-park · SPEC: Panda CSS and Radix export formats (renamed from "Panda CSS and Park UI export formats" at 0.2.0) · 2026-09-11 (v0.2.0, 2026-09-12) · approved
| Field | Value |
|---|---|
| Decision | Adds two NEW export formats, both Panda presets: `panda` (`exportPanda`, the full brand kit as `{ name, theme: { extend: { tokens, semanticTokens, textStyles? } } }` with unpadded stop keys `50…950`, `oklch()` strings everywhere, 53 resolved roles per palette as `{ base, _dark }`, plus fonts/textStyles/radii/spacing/borderWidths when `opts.type`/`opts.geometry` are given) and `parkui` (`exportParkUi`, a Panda preset in Park UI's colour shape: 12 solid steps + `a1..a12` Radix-style alpha projections per palette, the five appearance groups, `accent`/`gray` deep copies of the primary/neutral drivers, Park's global aliases, `radii.l1..l3`, no text styles). The 12-step projection (REQ-021, P-1 as corrected by #588): steps 1..8 are RAW RAMP STOPS (light 100/125/150/175/200/250/300/350, dark 900…650), steps 9..12 are the bare accent, `-hover`, `-on-surface-variant`, `-on-surface` roles; canonical table at `docs/reference/data/radix-projection.json`. The driver pick is extracted to `pickDrivers` shared with `exportShadcn` (byte-identical by fixture gate). Both formats are Pro-gated; a real `panda cssgen` leg runs as `scripts/smoke-panda.mjs` plus a `panda-smoke` CI job, never inside `npm test`. Ticket #614 renamed the format to Radix everywhere in live surfaces (`exportRadix`, id `radix`, folder `radix/`); the REQ sections are left under their original names and the version note is the record of the rename. |
| Forces | Panda preset grammar (`theme.extend` never bare `theme`, every leaf `{ value }`, `.dark` class condition, no `light-dark()`), `@park-ui/panda-preset` retired in favour of `@park-ui/cli` copying the preset into the consumer repo, Park recipes read appearance groups not raw numbers so a 12-step projection is REQUIRED, no zero-install Panda validator exists, `npm test` zero-dependency, `exportShadcn` structural precedent, 0.3.0 colour system (25 export stops, 53 roles, prime system, 16-palette default, data palettes never drivers), sibling #569 in flight owning the schema stamp |
| Rejected | picking 12 of the 25 stops evenly; the original P-1 role-indirection of steps 1..8 through `-surface-*`/`-outline-*` with steps 6..8 flattened over step 1 (superseded by #588); ADR-006 padded stop keys (N-1 ratified unpadded); hex for raw values (N-3); mapping the 15 voices onto Park's `xs…7xl` (H-2, not in v1); a Tailwind flavour of Park UI (KF-5 unresolved); invented Park keys (`bg.default`, `fg.disabled`, `border.muted`); emitting `light-dark()`; `colors.white`/`colors.black` (would override `preset-panda`'s) |
