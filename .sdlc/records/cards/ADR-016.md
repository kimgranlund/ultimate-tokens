# ADR-016 · One kebab-case naming grammar across every emitted surface; the moded collection is "Breakpoints" · 2026-07-17 · DECIDED (ratified 2026-07-17; execution TKT-0011..0014)
| Field | Value |
|---|---|
| Decision | Adopt the librarian grammar in full (8 rules): kebab-case for every emitted token/path segment on every surface (CSS, DTCG keys, JSON, UI3, Figma variable paths including voice/step segments), `/` as the only path delimiter, base-variant-modifier word order, suffixes always trailing, 3-digit stop padding, the homonym-check gate, and collection names per rule 8. Homonyms resolve by leaf rename (`size/*/gap` → `size/*/icon-gap`, `size/*/radius` → `size/*/pill-radius`). The canonical collection set is "Color Primitives" · "Color Semantic" (renamed from "Color Modes") · "Breakpoints" (renamed from "Geometry") · "Font Primitives". |
| Forces | the 2026-07-17 six-seat architecture review found emitted naming bimodal (kebab in CSS/Tailwind, camelCase in JSON/DTCG/UI3), a three-way collection-name split, the moded collection still named "Geometry" while hosting all of typography (TKT-0009), two homonym pairs, one grammar ends the C1/C2/M1 drift class at the root instead of per-emitter, kebab matches the shipped CSS surface, W3C DTCG style practice and the ratified TKT-0010 token names, engine-internal JS identifiers stay camelCase |
| Rejected | none named |
| Consequences | A one-shot migration wave (TKT-0013) across engine emitters, tests, consumer skills, the design-systems plugin, and BZZR, gated on the rename-capability prerequisite (TKT-0012) because all apply-loops reconcile by name and a bare rename orphans user bindings (collections-arch review, CRITICAL-1). Collection renames additionally migrate the provenance registry keys. Deliberate divergences stay fenced: Tailwind's literal `color` namespace, ShadCN's fixed vocabulary, Figma's all-pixel rule. Execution TKT-0011..0014. |
| Supersedes / amended by | supersedes none stated; amended by Amendment (2026-09-16) (the #491 ruling renamed the collection set again: "Color Semantic" → "Color Roles", "Font Primitives" → "Type Primitives", "Breakpoints" → "Geometry"; "Color Primitives" unchanged) |
