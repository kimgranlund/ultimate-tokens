## Gate interface (for U2 and U3)

- `--capture [--fixture <path>]`: measures and writes. If every value already equals the fixture, the file is left byte-identical (that is what makes C1.3's no-op hold); otherwise `capturedAt` = HEAD. Refused with `--damp-amp` or `--compare`.
- `--compare <base> [--fixture <head>]`: no measurement; prints `rose:` per cell above base + 0.05 (counts: any rise), a per-mode `byte-identical to base` / `moved against base` line, then `N cells rose (...)`; exit 1 on any rise. Self-compare prints `0 cells rose`; a head copy with `perceptual 300 median` +0.1 prints `1 cells rose (... perceptual 300 median)`, exit 1.
- Vacuity: a per-stop `n` different from the fixture's `n`, a non-finite measured cell, or a fixture missing a cell each fail loud.
