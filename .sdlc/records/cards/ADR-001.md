# ADR-001 · HCT (CAM16 H/C + CIELAB L*) over OKLCH-only · 2026-07-12 · DECIDED
| Field | Value |
|---|---|
| Decision | Use HCT: hue/chroma from CAM16, tone from CIELAB L*. OKLCH is the default input hue space (mapped to CAM16) and an output format; cam16 stays selectable (ADR-011). |
| Forces | OKLCH is the obvious modern choice and the user is fluent in it, HCT holds hue and tone stable across a ramp while maximizing chroma within gamut at each tone, perceptually even tonal scales for design-system ramps |
| Rejected | OKLCH-only |
| Consequences | Heavier engine (full CAM16 forward+inverse). OKLCH input requires a hue bridge, now the chroma-aware inverse (ADR-011, superseding the sampled ADR-008). |
| Supersedes / amended by | none stated; body references ADR-011 as the current hue bridge, which supersedes ADR-008 |
