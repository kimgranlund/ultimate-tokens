# ADR-007 · UI3 "Collections" schema is interchange-only, not native · 2026-07-12 · DECIDED (CAUTION)
| Field | Value |
|---|---|
| Decision | Keep the `figma-ui3-variables.color.schema.v1` export as a convenience/interchange format; do not present it as a native Figma Variables import format. |
| Forces | The schema string returns zero hits in Figma's documentation, it is not a verified native import path, importing it via the Variables modal will not resolve as a user might expect |
| Rejected | Presenting the UI3 schema as a native Figma Variables import format |
| Consequences | CAUTION flag on the record. Tracked as OD-003. |
