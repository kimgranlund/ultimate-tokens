# SITE-describe-palette · Describe-Palette MCP — Spec (words → brand kit, two-step, deterministic core) · 2026-07-18 · draft / design — build kickoff for umbrella feature #379
| Field | Value |
|---|---|
| Decision | An LLM only ever decides seeds, never colors: the calling agent interprets words into a `PaletteBrief` (`$id: "ultimate-tokens-palette-brief/1"`, families keyed by exactly the 8 canonical names Neutral · Primary · Secondary · Tertiary · Info · Success · Warning · Danger, per-family `hue`/`chroma`/`skew`/`lift`/`cuspPull`/`keyColor`/`supportColor`, `global.vibrancy`), and the pure deterministic `mcp/describe-kit-core.mjs` turns it into tokens via `toneMode:"perceptual"` + `hueSpace:"oklch"` forced. One `generate_kit` tool with two modes: `{description}` returns a self-teaching briefing payload (rubric, schema, exemplars, research instruction) and never generates; `{brief}` generates, with `brief` winning if both are given. Briefs clamp through `persist.js` domains rather than reject (§4.4). Absent-family defaults: Neutral follows Primary, Secondary = complement of Primary (180°), Tertiary = analogous of Secondary (30°), status families from role-table defaults with a bounded brand-hue nudge; a status distinctness gate enforces `MIN_HUE_SEP = 25°` with `STATUS_BANDS` halfWidth 20° and `BRAND_NUDGE = 8°`, falling back to chroma. Result = `{kit, doc, lint, meta}` text block + a zero-dependency PNG swatch board (376×528, light and dark stacked) image block; `meta.brief` is the replay handle. The generator merges into the brand-kit read server as separate `brand-kit-merged-core.mjs`/`brand-kit-merged-server.mjs` with `export_tokens(format)` (8 enum values). Parity is tool-surface parity at three gates G1 core↔app, G2 surface, G3 output, with `list_kits`/`kit` and the hosted-only `describe_palette` the only permitted asymmetries (ADR-021). Both flavors are Pro-gated via a new `describePalette` flag: locally at download time in `app.js#downloadDescribePaletteMcp`, hosted server-side. Packaging is a separate `<kit>-describe-mcp.zip` beside the free `<kit>-mcp.zip`. |
| Forces | MCP users have no nonoun skills or corpus so the method must travel inside the tool result, no server-side LLM in the local flavor (#371), the shadcn emitter matches family names by regex, determinism and reproducibility (same brief + engine version → deep-equal kit), zero new runtime dependencies (PNG encoder is hand-rolled stored-deflate), Pro-gated by the #379 ruling (2026-07-18), the hosting spec's "generator stays client-side" constraint breached for the hosted flavor and ratified as ADR-021 (#376), a downloaded stdio server has no live entitlement check to call, `CONTRAST_MIN = 3.0` matches the app's fixed `onColorMode` floor (ADR-003) |
