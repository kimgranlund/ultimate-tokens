# ADR-013 · Editorial type voices (7 → 11) + the box/flow decoupling · 2026-07-12 · DECIDED (updated 2026-07-13, three times)
| Field | Value |
|---|---|
| Decision | Add four editorial voices (Lead on the body role, Quote on the heading role, Caption and Legal as fine-print) via `make11()`, all riding existing font roles so no new font is introduced; each new voice uses a 3-step `STEPS_3` ramp (total steps 41 → 53); a new per-voice `box` field decouples presentation flow from font role (defaults from the role, Caption + Legal ride the ui font but set `box:false`); treatment integration is hybrid with a few per-voice knobs. |
| Forces | the seven-voice taxonomy lacked standfirst/lede, pull quote, caption and fine-print roles, engine emitters are generic so a new voice auto-flows from one `cat()` line, `role` conflated the font, the paragraph flow and the character, a voice is a function so editorial roles are voices not Body levels, riding existing roles keeps the blast bounded |
| Rejected | none named |
| Consequences | Emitters (CSS/DTCG/Figma/MCP) auto-flowed. Lockstep edits: `persist.js` VOICES allowlist (else per-voice overrides drop on hydrate), test count literals (`GROUPS` 11, headless 53 steps / 11 groups), `styles.css` `.ty-s0…10` series colours, `TYPE_SPECIMENS`/`SHORT` maps. There is NO code-enforced type answer-key; `typography.tokens.json` is a frozen reference snapshot and `voice-parity.mjs` auto-derives the voice list from the live engine; the spec/README/marketing "seven"→"eleven" doc drift is serviced in the same change. Update 2026-07-13: voices renamed (Heading→Headline, UI→Label; Quote folded into Lead, Caption into new Tiny, Legal into Body; Title and Sub-title added), every voice a uniform 3-step SM/MD/LG ramp at fixed hand-authored sizes shared across all 5 treatments, `ratio` retired. Later update: count eleven → thirteen (`Code` renamed `Body-mono`, `Label-mono` and `Tiny-mono` added, Tiny sizes 10/11/12 → 9/10/11, `make11()` renamed `makeVoices()`). Later update: `siblingWeightDefaults(core)` moves from 2 stops to 3, every voice's `weights` auto-populated by default in `typeScale()` (`[]` is the opt-out), Figma CORE style name segment becomes dot-prefixed Title-Case (`Body/md/• Regular`). |
