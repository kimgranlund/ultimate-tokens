# ADR-009 · Fixed viewing conditions (no VC controls) · 2026-07-12 · DECIDED
| Field | Value |
|---|---|
| Decision | Derive one fixed VC (`makeVC`: average surround, bg 50, mid-gray adapting luminance) at load. Do not expose VC controls. |
| Forces | CAM16 is parameterized by adapting luminance surround and background, target is screen sRGB under average surround (one stable appearance context), exposing VC would make exports non-portable and the chroma peaks unstable |
| Rejected | Exposing viewing-condition controls |
| Consequences | none stated beyond the rationale (exports stay portable, chroma peaks stay stable) |
| Supersedes / amended by | none stated |
