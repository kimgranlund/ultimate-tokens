# SPEC-muted-base · SPEC — Muted base ramps, a per-palette prime system, and 8 brand-derived data palettes · 2026-09-11 (v0.3.0) · approved
| Field | Value |
|---|---|
| Decision | Retires the chroma spike on the base ramp entirely (0.2.0, #533) and replaces it with a per-palette PRIME SYSTEM: seven mode-independent primitives-tier swatches (`brightest`…`dimmest`) on their own OKHSL `l` ladder (`PRIME_STEP 0.09`, edge-compressed into `[0.14, 0.94]`, anchored on the key colour's own OKHSL coordinates so `prime` equals `deriveKeyColor` exactly at `primeChroma 100`), emitted as a `prime` token group in every format except ShadCN and as a new Figma collection `Color Prime` with a single `Base` mode. 0.3.0 (#556/#559) adds user-assignable editor-only PALETTE GROUPS (material, brand, system, data) whose `baseChroma` is the ABSOLUTE ramp chroma target shared by every ramp in the group (defaults material 30/60, brand 100/100, system 100/100, data 100/100 locked); `palette.chroma` feeds only the key colour and prime system; `palette.intensity` and `intensityAt` are removed; schema version becomes 4. Data palettes: `defaultDocument()` returns 16 palettes (8 brand families + `Data 1..8`), hues derived once at mint by `deriveDataHues` (even 360/count spacing plus the integer offset maximising min distance to chromatic brand hues), chroma follows the primary's. |
| Forces | the 53-role table and `role-table.json` frozen, a discrete spike made the ramp patchy (the defect #533 closes), Helmholtz-Kohlrausch gap between a chromatic colour and grey at the same L* (#537 ruling), Abney drift from re-solving hue at one `s` and rendering at another, `tonal.js` legacy fixture as a hard wall, `story.groups` already names a different concept (key must be `paletteGroups`), 5,000-variable Figma collection ceiling, byte-identity of `paletteStops` to 0.2.0, zero-dependency `npm test` |
| Rejected | any chroma spike or identity-stop set on the base ramp; roles aliasing prime tokens this round; a per-scheme prime ladder or Light/Dark mode on `Color Prime` (R2); per-palette ramp chroma override in any group (0.3.0 retires 0.2.0's `I(stop) = b` multiplier); a hue re-solve in the prime system (`solveOkhslHue`, ruled out on #537); anchoring `l_prime` on the neutral grey at the cusp tone; `lift`/`damp*`/`vibrancy`/`cuspPull`/`toneMode` applying to the prime ladder; groups entering token names, Figma paths, the role table, or MCP output; prime tokens in ShadCN; a migration that adds palettes to a saved document |
| Consequences | Token count per enabled palette becomes 96 (25+11+53+7); default document 16 × 96; Figma binding plan 848, primitives 576, prime 112. Neutral, Primary, Tertiary, Info, Success, Danger and the default data palettes CHANGE values by design; Secondary and Warning stay byte-identical. AC-001..053 name the gates (`test/engine/prime.mjs` new verifier with independent `up`/`down` re-derivation and pixel-measured hue as anti-tautology controls; `test/ui/fixtures/default-doc-ramps.json` regenerated only by `scripts/gen-ramp-fixture.mjs`). Companion LLD: `docs/lld/lld-muted-base-key-spikes.md`. Intent records: issues #503, #533; rulings on #537, #556, #559; strip naming references #552; migration precedent TKT-0016; `DROPPED_KEYS` precedent TKT-0455. Open follow-up only: material 30/60 values may be tuned after a Safari look (#559 Open 2). ADR ids cited: ADR-016 (two-segment token shape), ADR-017 (git-native tickets). |
