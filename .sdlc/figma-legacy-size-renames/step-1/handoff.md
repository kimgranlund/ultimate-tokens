## Task goal
Independent review of PR #813 (T-0017, Maison geometry ladder, `git show e084b9f0`) found a data-loss path. Old variables only alias or deprecate in library mode (`figma/plugin/code.js` ~:1157, `src/ui/overlays/apply-gate.js` ~:79 and :106, `figma/binder/migrations.mjs` ~:35). The flagship sends `libraryMode=false` by default (localStorage), and the new cells get no `renames` entry because `kebabWaveOldName` returns null for `size/{cell}/*`. So the first Apply on an existing Figma file prunes every `size/{xs..2xl}/*` and `type/ui-control|ui-widget/{non-md}/*` variable, and every bound layer and text style detaches. ADR-032's "Figma:" bullet says "alias to cells ... deprecate id-preserving" without saying that only holds in library mode.

## Step 1: Classic-mode legacy size renames and the ADR-032 amendment
level: L3
### Read first

### Do
Read the `maintaining-figma-plugins` and `figma-file-migration` skills first. This step adds no code to `figma/plugin/code.js` or the binder `code.js`. The reason: `applyFloatPlans` (flagship `figma/plugin/code.js`, the `for (const [oldName, newName] of Object.entries(plan.renames || {}))` loop) already runs `plan.renames` with the id kept, in both modes, before the alias reconcile and the prune. `pruneCandidatesVM` (code.js) and `pruneCandidates` (`figma/binder/mode-apply-plan.mjs`) both skip `_deprecated/` names. So the fix is a new rename map that the UI stamps into the plan. Depends on: none.

1. `figma/binder/migrations.mjs`:
   - Add `import { LEGACY_SIZE_CELLS } from "../../src/engine/geometry.mjs";`. Read the engine; never edit it.
   - Add a frozen-history const, `export const LEGACY_SIZE_FIELDS = ["height", "icon", "caret", "icon-gap", "padding-narrow", "padding-wide", "padding-narrow-compact", "padding-wide-compact", "pill-radius", "min-width"]`. These are the ten kebab `size/{step}/*` fields the engine emitted before T-0017, over the steps xs, sm, md, lg, xl, 2xl. Also add the retired UI-step tables:
     - voices `ui-control`, `ui-widget`
     - steps `xs`, `sm`, `lg`, `xl`, `2xl`
     - props `size`, `line-height`, `letter-spacing`, `weight`, `paragraph-spacing`, `single-line-height`
   - Add `export function legacySizeRenames(currentNames, mdCell)`. It returns `{ oldName: newName }`, with these rules:
     - (a) `wanted = new Set(currentNames)`. Never emit a key that is a wanted name.
     - (b) Walk the steps as `[["MD", mdCell], ...Object.entries(LEGACY_SIZE_CELLS)]`, so MD claims its cell first. A step owns its cell only when the cell is non-empty, not already claimed, and `size/{cell}/height` is wanted. A step whose cell is taken or missing gets only `_deprecated/` targets.
     - (c) For each field in `LEGACY_SIZE_FIELDS`, the target field is the same field when `size/{cell}/{field}` is wanted. Otherwise it is `GEOMETRY_FIELD_RENAME_MAP[field]`: padding-narrow maps to inset, and pill-radius maps to radius-control.
     - (d) Each legacy kebab name `size/{step lowercased}/{field}` and its pre-ADR-016 spelling `kebabWaveOldName(kebabName)` (for example `size/MD/height`, `size/XS/paddingWide`) map to the target when the target is wanted, and to `"_deprecated/" + <that same old spelling>` otherwise.
     - (e) Every retired `type/{voice}/{step}/{prop}` and its `kebabWaveOldName` spelling map to `"_deprecated/" + <old spelling>`.

     Keep `OLD_FIELD`, `kebabWaveOldName` and `kebabWaveVarRenames` unchanged. The new path sits beside them and does not go through them; the guard below pins this.
   - The settled choice for the retired UI steps is deprecation with the id kept, not a map to md. This follows the `size/{step}/font` precedent, which is the "SAME scope decision covers the retired UI voice steps" paragraph in the `GEOMETRY_FIELD_RENAME_MAP` header. State that in the new function's header comment.
   - The `mdCell` argument is the engine's legacy-MD resolver, `sizeAnchor(scale, "MD").name` (`src/engine/geometry.mjs`, `sizeAnchor`). `LEGACY_SIZE_CELLS` has no MD key because MD is the kit default cell.
2. `src/ui/overlays/apply-gate.js`:

   - Change the signature to `_figmaFloatPlans(opts = {})`. When `opts.legacyRenames === true`, each plan gets `legacySizeRenames(planNames, sizeAnchor(this._geomScaleFor("base"), "MD").name)`, merged as `p.renames = { ...waveVars, ...legacy, ...(p.renames || {}) }`.
   - With no argument the output stays unchanged. `_figmaChangedCount` and `src/ui/app.js` `_figmaFloatPlans()` call it that way, and `app.js` is off-limits.
   - In `applyToFigma`, read `this._libraryMode()` once. Send it as `libraryMode`, and build `floatPlans: this._figmaFloatPlans({ legacyRenames: !libraryMode })`.
   - Add a comment that library mode keeps ADR-032's nearest-by-height alias and deprecate path. Stamping renames there would turn every alias into a rename, because renames run before the reconcile.
