## Goal
Rebuild the Geometry system of ultimate-tokens on the Maison ui-kit geometry system (user decision 2026-10-07: "for the Geometry system, let's use the maison ui-kit system... we should name tokens according to our standards of course, but this is a standard system to follow for now"). ## Source of truth (read only, another repo, never edit it)
`/Users/kimgranlund/Projects/maison/ui-kit-maison/src/foundation/geometry/`: `contract.json`, `component.md` (generated from the contract), `geometry.css` and `geometry.ts` (the resolver), and the CSV ladder under `geometry/tokens/`. The sender's summary, verbatim:

- Sizes every control from three independent axes set as data attributes on any ancestor: `data-tier`, `data-scale`, `data-size`; nearest value of each axis wins, so one page can mix sizes (including inside shadow roots). The axes resolve to a ladder of 27 cells (tier x scale x size). product/md/md is the 32px control.
- Public roles on the element: `--g-height` (control height, drives `--control-height`), `--g-inset` (inner padding), `--g-text` (control text size), `--g-caption-text` (largest ladder text at or below height minus inset), `--g-icon-height-ratio` (icon height / control height, dimensionless), `--g-chip-height`, `--g-chip-inset`, `--g-chip-text` (compact label roles, same lookup row, chip height capped at the caller's height), `--r-control` (control radius from the radius mode), `--r-mark` (icon/mark radius = `--g-icon-height-ratio` x `--r-control`). Radius mode is `data-radius` (four named modes; "round" is the default; "default" keeps the 0.5 coefficient mode).
- Theme usage: set the axes once high up (`<body data-tier="product" data-scale="md" data-size="md">`), override on a subtree to show another size, size pieces from the roles never from fixed px (`min-block-size: var(--g-height); padding-inline: var(--g-inset); font-size: var(--g-text); border-radius: var(--r-control)`), each role is independently overridable, do not use the imported `--md-sys-size-*`, density classes or fixed control classes (historical snapshots, not aliases), a native control's own `size` attribute keeps its HTML meaning (Maison uses `data-size`), a theme pack may change colors, presentation and layout inputs but changing the size ladder needs validation of all 27 cells.
