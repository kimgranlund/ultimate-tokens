## Approach

The analysis rail's twelve `html:` SVG sites are three kinds of drawing, not twelve charts: nine Cartesian line plots (`graphLC`, `graphTone`, `graphChroma`, `graphDamping` in `src/ui/sections/color.js`; `graphTypeScale`, `graphTypeTracking`, `graphTypeLeading` in `typography.js`; `graphGeomPower`, `graphGeomBands` in `geometry.js`), two polar dot plots (`graphHueWheel` :213 and `_hueCircle` :600 in `color.js`), and one static diagram (`graphGeomCentering`, `geometry.js` :464). `graphContrast`, `graphGeomComposition` and `graphTypeRoles` are already native DOM (`.an-bar`/`.an-track`) and are the house style the ports match. All twelve port to HTML/CSS marks; none needs to stay SVG. The source project's only trick that matters here is the stroke ribbon (`strokeRibbon`, `/Users/kimgranlund/Projects/nonoun/native-dom-charts/src/lib/core/geometry.js`): one `clip-path: polygon()` per non-missing run on a filled div, miter-bounded, so a polyline is one element. The polar plots are a bordered circle plus absolutely positioned dots at `left/top` percent (the source's Radar renderer), and the centering diagram is two nested squares plus two thick rules. Dashed curves (seven classes today: `lc-toneline`, `dg-unity`, `gp-ref`, `ty-s3/s9/s10/s12`) have no clip-path equivalent; axis-aligned ones become a `border-top/left: 1px dashed` rule, curved ones get a `mask-image: var(--dash)` repeating gradient on the ribbon, which reads as dashes on the near-horizontal ascending series these all are.

Layering follows the source (`core -> renderers -> composition`) inside this repo: `src/ui/charts/core.mjs` is pure and DOM-free (scales, runs, ribbon and band polygons, polar placement, `resolveChart(spec)` to mark primitives, `sourceRows`), `src/ui/charts/render.mjs` imports `h` and paints primitives as elements, and the section files shrink to spec builders that read the engines as they do today (`view.plot[idx].points`, `vp.ramp`, `chromaEnvelope`, `scale.cells`, `series.steps`). Coordinates stay in each chart's nominal px box (W 244 x H, the constants already in the code), the core converts to percent, and the root carries `aspect-ratio: W/H; width: 100%; max-width: Wpx`, so the box scales uniformly, no ResizeObserver, no measurement, and the shim can read every number off `getAttribute("style")`. The cards are snapshot-tier by the source's own contract (no hit regions, two or three fixed labels), so there is no tooltip, keyboard, pin or label-culling path; the one accessibility obligation kept is a visually hidden `<table>` per chart generated from the same series data, plus `forced-color-adjust: none` on the mark layer.

Series paint moves from SVG `stroke`/`fill` attributes to one custom property (`--series`, plus `--dash` on the mono voices) set by the existing class names (`.ty-s0..14`, `.lc-*`, `.gp-*`) and read by ribbons, dots and the legend marks alike. Chart sizing comes from tokens on `.an-chart` (`--chart-stroke: 1.5px`, `--chart-ref: 1px`, `--chart-dot: 4px`). The `html` branch of `h()` (`src/ui/app-helpers.mjs:324`) has no caller outside the three section files and is deleted with the last port. Sequencing: core + renderer + their test land first as new files; `test/repo/svg-rules.mjs` is replaced in the same early step by `dom-charts.mjs` with an explicit allowlist of still-SVG function names (so `npm test` stays green through every port, the old gate goes red the moment one `html:` disappears); the per-section ports follow after T-0025 (`color.js`, `styles.css`, `app.js`) and T-0027 (`geometry.mjs`) land, one writer per file; then the `h()` cleanup, the SVG CSS deletion, and the records. Manifest: `/Users/kimgranlund/Projects/nonoun/ultimate-tokens/.sdlc/native-dom-charts/decompose/manifest-v1.json` (coverage check clean, plan mode, 36 nodes, 38 actions, 22 edges); report beside it.

## Rejected alternatives

- Core under `src/engine/`: the engines are the token engines (color, type, geometry); chart math is a UI concern with no export surface, so it lives in `src/ui/charts/` and stays DOM-free by import discipline (no `h`, tested by `test/ui/charts.mjs` under plain Node).
- Fluid plots with measured stroke (the source's ResizeObserver): the rail is fixed at 290px and the shim cannot measure, so nominal px boxes with percent polygons give identical output in tests and the browser.
- Per-segment rotated divs with `border-top: dashed` for dashed curves: one element per segment, seams at joins, and px lengths that break under box scaling; the mask is one declaration on the existing ribbon.
- Tooltips, keyboard traversal, pinning, label culling from the source's interaction contract: the cards are snapshot-tier (no hit regions, fixed labels); adding interaction is a feature, not a port, and belongs in its own ticket.
- Keeping the four geometry drawings as SVG under a narrowed exception: each is a circle, dots, squares and rules, all native-DOM primitives already needed by the Cartesian charts; keeping them would preserve the `html:` path, the `h()` branch and the SVG CSS for three functions.
- Blocking on the user ruling for those four: the handoff scoped the architect to classify and surface; blocking would discard the design for the nine portable charts.
- Swapping the gate last (after all ports): leaves `npm test` red from the first port to the last, breaking every builder's floor; the allowlisted gate lands first.

## Risks

- A "keep SVG" ruling on the wheel, disc or centering cell removes `cleanup.h`, `styles.cleanup` and the zero-count assertion in `gates.repo`; that needs a manifest v2 and a narrowed allowlist, not a different design.
- The mask-dash encoding may read poorly on steep runs (the Chroma ceiling at the ramp ends); the pixel review decides, and the fallback is faint solid ribbons with the legend unchanged (legend marks are already solid bars).
- The hidden source table adds roughly 3 x samples nodes per chart on every `liveRefresh`; if the smoke leg shows the rail re-render cost rising, the table can become opt-in per spec without touching the core.
- T-0025 edits `color.js`/`styles.css`/`app.js` and T-0027 edits `geometry.mjs`; if either lands after the ports start, the section steps rebase; the core/renderer/test/gate steps are unaffected (new files only).
- Safari `mask-image` without the `-webkit-` twin silently drops the dashes on older Safari; the builder must write both.
- `test/ui/headless-boot.mjs` (q3) is the only existing test that inspects chart internals; other groups count `.an-card` only, so a chart that renders empty would pass headless and be caught only by the smoke `evalJS` assertions.
