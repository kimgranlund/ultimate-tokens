# LLD-app-shell · LLD — The App Shell (`HctApp`) · 2026-07-12 (last edit 2026-09-13) · as-built (descriptive; no frontmatter status)
| Field | Value |
|---|---|
| Decision | Describes the shipped shell as-built: `HctApp` is one vanilla custom element in light DOM with two top-level views (`gallery`, `editor`), and the editor is a fixed 3×3 CSS grid (header · left 290px / center / right 300px · footer) with pane collapse as a class on `.editor` that zeroes a column track. One `this.section` ∈ {color, typography, geometry} re-routes all three panes; state splits into persisted `this.doc` (mutated only via `editDrag`/`commitDrag`) and ephemeral ui-session fields that are never persisted. Full `render()` rebuilds the whole subtree; `liveRefresh` patches only `.canvas-scene` children, `.an-body`, and the two paint-in-place footers during a drag, bailing to a full render in Both/Compare mode. Assigns stable `SPEC-R1..R12` handles to ui-plan.md's T1–T9 tasks and Revision A; every shell component `LLD-C1..C10` traces to one. |
| Forces | no framework (h() hyperscript, light DOM, native `<dialog>`), focus/caret preservation during a slider drag, one editor for three composing systems, headless shim limits (single-class `querySelector`, no `id`/`textContent`), anti-gold-plating (a region with no `SPEC-R#` trace does not belong), context-is-memory rule |
| Rejected | a dashboard posture ("never a dashboard"); a separate numbered SPEC for the shell (ui-plan.md's clauses are reused under `SPEC-R#` handles instead) |
| Consequences | Extension order is fixed: frame → state axes → header/switcher → all three pane branches (a new section needs all three or renders a stale sibling) → paint-in-place hooks wired into both full render and `liveRefresh` → bump lettered-group count literals in `test/ui/headless-boot.mjs`. A change to the grid, a mount point, the render/liveRefresh split, or a section/tab count invalidates this LLD and must update it in the same change; a wrong `UI:T*` requirement is fixed in `ui-plan.md` first. Governing spec named: `docs/reference/references/ui-plan.md`; engine/role contracts live in `knowledge-01…06` + `data/role-table.json`. No tickets or issues named. No ADR ids cited. |
